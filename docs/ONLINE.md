# 联机、补给和切刀更新

## Vercel 上使用

这是 Vite 静态站点，保持现有 Vercel 配置：构建命令 `npm run build`，输出目录 `dist`。将这次修改推送到已关联的 Git 仓库并重新部署后，新功能才会出现在正式站点。

1. 大厅选择地图和配装，点击 **联机对战**，输入昵称，点击 **创建房间**。
2. 按 Esc 打开暂停菜单，点击屏幕下方的房间码复制邀请链接，发给朋友；也可以直接告诉朋友 8 位房间码。
3. 朋友打开链接，填写昵称并点击 **加入房间**。每个房间最多 8 人，不填充机器人。
4. 房主主持 5 分钟自由混战。血量、弹药、命中、近战、道具、复活和计分由房主统一判定。死亡后 3 秒复活。
5. 暂停菜单只暂停自己的输入，联机比赛继续。房主可在结算后再开一局；其他玩家等待房主。返回大厅即离开房间，房主离开会关闭房间。再次输入房间码可重新加入，战绩从零开始。

这是好友房间模式，房主浏览器必须保持开启，建议保持标签页在前台。浏览器对后台标签页的限速或休眠可能影响对局。当前没有房主迁移、账号匹配或竞技反作弊服务；联机对局不发放本地武器 XP。

## 信令和网络配置

默认使用 [PeerJS 公共信令服务](https://peerjs.com/client/getting-started) 帮助浏览器建立 WebRTC DataChannel，建立连接后对战数据在玩家和房主之间直接传输。不需要在 Vercel Functions 内保存房间状态，也不需要额外的 Vercel 环境变量。

**静态托管不等于所有网络都能直连。** 公共信令服务必须能从双方网络访问；某些公司网络、运营商 NAT 或防火墙需要 TURN 中继。若连接超时，检查房间码、双方游戏版本和网络，并使用以下可选配置。

Vercel Project → Settings → Environment Variables 可配置：

| 变量 | 用途 | 默认值 |
| --- | --- | --- |
| `VITE_PEER_HOST` | 自建 PeerServer 域名，不含协议 | PeerJS 公共服务 |
| `VITE_PEER_PORT` | 信令服务端口 | `443` |
| `VITE_PEER_PATH` | 信令服务路径 | `/` |
| `VITE_PEER_SECURE` | 是否使用 HTTPS/WSS；仅本地测试设为 `false` | `true` |
| `VITE_ICE_SERVERS` | JSON 格式的 WebRTC ICE/STUN/TURN 配置数组 | PeerJS 默认配置 |

`VITE_ICE_SERVERS` 示例：

```json
[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:turn.example.com:3478","username":"limited-client-user","credential":"limited-client-credential"}]
```

这些 `VITE_` 变量会打包进公开的浏览器代码，不能放服务管理密钥。正式 TURN 服务建议通过服务端接口签发短期凭据；示例只说明配置格式。修改变量后需要重新构建并部署。

## 随机补给

- 每张地图 5 份弹夹、5 个血包，使用与导航图相连且人物能站立的位置，避开障碍物，并尽量彼此分开。
- 走近自动拾取，不需要按键；不能隔墙拾取。
- 血包回复最多 35 HP，最高 100 HP，20 秒后在新随机位置刷新。
- 弹夹给主武器和手枪各补充一个弹匣容量的备弹，不超过各自备弹上限，15 秒后在新随机位置刷新；不会直接填入当前弹匣。
- 满血或所有备弹已满时不消耗对应道具。单机机器人也可拾取；联机房主决定唯一拾取者，并同步到所有玩家。

## 切刀

保留切刀 0.75 秒的操作成本，前 0.12 秒放低旧武器，随后拔刀、转腕、轻微回弹并归位。移除了手臂和刀一起旋转一整圈的动作。切换中不能开枪或刺击；连续切换会取消旧的攻击及换弹。

## 验证

```sh
npm run build
# 先开另一个终端运行 npm run dev
npm test
npm run test:pickups
# 自动启动本地信令服务器与独立 Vite；不依赖公网信令
npm run test:online
```

测试默认使用 Windows Chrome 路径；其他环境通过 `CHROME_PATH` 指定浏览器。联机测试使用 `5174` 和 `9001` 端口，以两个独立浏览器上下文通过真实 WebRTC 检查连接、枪击、近战、移动、换弹、补给、击杀、复活、结算、再开一局与离开/重入。测试结果保存在 `test-results/online-report.json`。
